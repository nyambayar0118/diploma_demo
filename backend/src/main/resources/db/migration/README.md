# Өгөгдлийн сангийн шилжилтүүд (Flyway)

Өгөгдлийн сангийн бүтцийг эдгээр файлууд дарааллаар нь үүсгэнэ. Сервер эхлэх бүрд Flyway хэрэгжээгүй
шилжилтийг ажиллуулна.

**Анхааруулга:** хэрэгжсэн шилжилтийн файлыг (тайлбарыг нь ч) өөрчилж болохгүй. Flyway файл бүрийн checksum-ийг
хадгалдаг тул өөрчлөгдсөн файл олдвол сервер эхлэхгүй. Иймд эдгээр файлын доторх тайлбар англиар үлдсэн бөгөөд
агуулгыг нь энд монголоор тайлбарлав. Шинэ өөрчлөлтийг үргэлж дараагийн дугаартай шинэ файлаар нэмнэ.

| Файл | Агуулга |
|---|---|
| `V1__extensions.sql` | PostGIS (орон зайн өгөгдлийн төрөл, индекс, функц) болон pg_trgm (кирилл, латин нэрээр төстэй байдлаар хайх, АШ01, АШ02) өргөтгөл |
| `V2__places_schema.sql` | Газрын модулийн хүснэгтүүд: ангилал, OSM шошгын харгалзуулалт, барилга, газар, гадаад холбоос, osm2pgsql-ийн завсрын `osm` схем. Солбилцол WGS84 (EPSG:4326). Монгол кирилл бичгийг латин руу галиглах функц |
| `V3__seed_categories.sql` | Хоёр түвшний газрын ангилал ба OSM шошгын харгалзуулалт (`data/categories.py`-аас үүсгэсэн). Үндсэн ангиллыг өөрийг нь биш, дэд ангиллыг нь санал болгоно |
| `V4__more_category_mappings.sql` | Улаанбаатарын анхны импортын дараа нэмсэн харгалзуулалт: хөшөө, урлагийн бүтээл (түүхэн дурсгал), гоо сайхны салон (хайлтад гарах боловч санал болгохгүй) |
| `V5__users_and_interests.sql` | Нэвтрэлтийн модуль (хэрэглэгч, тохиргоо, хувийн мэдээллийн зөвшөөрөл) болон Сонирхлын профайлын модуль (бүртгэлийн асуулга, сонирхлын жин) |
| `V6__marks_and_interactions.sql` | Хадгалсан / нуусан газар болон хэрэглэгчийн үйлдлийн бүрэн бүртгэл (машин сургалтын өгөгдөл); нэрийг латинаар галиглан хайх багана |
| `V7__recommendations.sql` | Санал болголтын багц, эрэмбэлсэн санал болголт (LambdaRank-ийн сургалтын өгөгдөл, нэг багц = нэг асуулгын бүлэг), ангиллын цагийн тохирц |
| `V8__routes.sql` | Маршрут, зогсоол, сэтгэл ханамжийн үнэлгээ. Систем замыг өөрөө зурахгүй: зогсоолыг дараалуулж, хугацааг тооцоод Google Maps руу шилжүүлнэ |
| `V9__account_deletion.sql` | ХШ08: бүртгэл устгасны дараа маршрут эзэнгүй, эхлэх цэггүйгээр нэргүй үнэлгээний өгөгдөл болж үлдэнэ |
| `V10__reviews.sql` | Үнэлгээ, сэтгэгдэл (АШ16) болон модераторын нуух (АШ17); хэрэглэгч газар бүрд нэг сэтгэгдэл |
| `V11__friends_and_locations.sql` | Найзын модуль (АШ20) болон байршлын модуль (АШ21, ХШ07); зөвхөн сүүлийн байршлыг хадгална |
| `V12__groups.sql` | Бүлгийн төлөвлөгөө (АШ10, АШ24): найзууд болон урилгын холбоосоор нэгдсэн зочдын уулзах газар |
| `V13__contributions.sql` | Хувь нэмэр (АШ03-АШ06, АШ18, СНШ10): шинэ газар, засвар, холбоосын хүсэлт, урамшууллын оноо; баталгаажсан засварыг OSM-ийн дахин импортоос хамгаална |
| `V14__recommendation_category_filter.sql` | Санал болголтын хүсэлтийг хязгаарласан ангиллыг багцтай хамт хадгална (шүүсэн жагсаалт хэрэглэгчийн сонирхлын талаар бага мэдээлэл өгдөг) |
| `V15__minu_source.sql` | Minu Map-ийг OpenStreetMap-ийн хажууд хоёр дахь эх сурвалж болгоно: `MINU` эх сурвалж, `minu_id`, `minu_data`, Minu ангиллыг манай ангилалд харгалзуулах хүснэгт |
